# Modos del skill Ariadne

Ariadne distribuye un solo skill instalable: `skills/ariadne/SKILL.md`. El enrutador puede sugerir `mode: lite` para tareas sencillas de backlog y ledger, y `mode: full` para auditorías, desarrollo, Gantt o despliegues. Ambos modos cargan el mismo skill; el modo liviano reduce el alcance operativo, no instala otra extensión.

Usa el launcher para ver la sugerencia: `npm run ariadne:launcher -- "mueve la tarea a cola"`.
