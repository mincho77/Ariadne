Cómo pedirle algo a Ariadne

Escribe en lenguaje normal desde el chat del proyecto. No necesitas recordar comandos de terminal.

  • Auditar el proyectoAriadne, audita este proyecto completo con una DAFO y explícame su viabilidad.
  • Ejecutar una mejoraAriadne, ejecuta JM-E-12 con planificación, pruebas y árbitro adversarial hasta PASS o BLOCKED.
  • Ver qué sigueAriadne, revisa el plan de este proyecto y dime el siguiente paso.
  • Corregir y desplegarAriadne, audita y corrige este proyecto; despliega localmente si las verificaciones y el destino están claros.

En Codex, escribe $ariadne para invocar la skill o usa /skills para buscarla. Si la invocas sin una tarea concreta, Ariadne puede mostrarte estas opciones.
